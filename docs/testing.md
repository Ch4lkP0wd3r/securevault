# Testing Approach

SecureVault includes automated tests for its core functionality.

## Areas Tested

- Vault creation and access
- Encryption/decryption behavior
- Incorrect master-password handling
- Tampering/integrity detection
- Salt uniqueness
- Protection against plaintext storage
- Password generation
- Password-strength evaluation
- Duplicate credential handling
- Input validation
- Credential update and deletion
- Multiple accounts for the same service
- Password-reuse auditing
- Serialization
- End-to-end CLI workflow

## Test Result

The submitted project test suite contains **19 automated tests**, all of which passed during the project review:

**19 passed, 0 failed**

Testing provides evidence that the implemented functions behave as expected for the tested scenarios.
